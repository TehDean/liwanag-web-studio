# Northline Studio (preview)

Landing page and four sample client sites (personal trainer, caterer, realtor, photographer) for a no-code website studio in West Orange, NJ.

All businesses, prices and reviews on the sample sites are fictional. Photos are from Pexels.

The pages ask search engines not to index them while the studio name and contact form are placeholders.

`dc.js` is a small script that renders each page's template and runs its interactive parts (booking pickers, menu tabs, gallery filter, chat bubble).
